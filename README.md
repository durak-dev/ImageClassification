# ImageClassification
Image classification project: preprocessing (quality check + restoration), label audit with CLIP, and CNN training with Keras.

The dataset lives **inside this repository** (`data/labels.csv` and `data/images/`). There is no external download.

```
data/            labels.csv + images/   (input, committed to git)
dataset_fixed/   restored images        (generated by the notebook, git-ignored)
utils/funcs.py   helper functions
Preprocessing.ipynb
requirements.txt
```

## Option A – Run locally (GPU or CPU)

1. Clone the repo and enter it:
   ```bash
   git clone https://github.com/durak-dev/ImageClassification.git
   cd ImageClassification
   ```
2. Create a virtual environment and activate it:
   ```bash
   python -m venv .venv
   # Windows:  .venv\Scripts\activate
   # Mac/Linux: source .venv/bin/activate
   ```
3. *(Only if you have an NVIDIA GPU)* install the CUDA build of PyTorch first, using the command for your CUDA version from <https://pytorch.org/get-started/locally/>. Otherwise skip this step; the CPU build is installed in step 4.
4. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Open `Preprocessing.ipynb` (Jupyter or VS Code, select the `.venv` kernel) and run the cells top to bottom.
   The "Imports and hardware" cell prints whether `cuda` or `cpu` is used; the GPU is picked automatically if available.

## Option B – Run on Google Colab

1. Open Colab, then *File → Open notebook → GitHub* and enter `durak-dev/ImageClassification` (or upload `Preprocessing.ipynb`).
2. *(Optional)* *Runtime → Change runtime type → GPU* to speed up CLIP.
3. Run the cells top to bottom. The setup cell detects Colab, clones the repo into `/content/ImageClassification` (or pulls the latest changes) and uses the data from there. Colab already has the required packages.

## Notes

* Pull before you start (`git pull`) so everyone uses the same `funcs.py` and data.
* `dataset_fixed/` is regenerated by the notebook; do not commit it.
* Quality thresholds (`NOISE_THRESHOLD`, `BLUR_THRESHOLD`) are defined once in the quality-check cell and reused by the restoration step.
